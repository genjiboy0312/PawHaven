# Settings 팝업

- 로비와 Play의 Settings 버튼에서 같은 팝업을 연다. 씬 전환 없음.
- 크기: 16:9 게임 영역 가로 64%, 세로 72%. 배경을 어둡게 하고 Sound / Controls / Display / Language / Account / About 6개 탭을 제공한다. 상단 탭은 가로 스크롤 가능하다.
- ×, Escape, 바깥 배경 클릭으로 닫기. 뒤쪽 UI inert 처리, 키보드 포커스 순환 및 복귀 지원.
- SceneManager가 게임 시뮬레이션을 일시정지한다. Play의 입력도 차단하고 유지 중인 이동 키/조이스틱을 초기화한다. 팝업 닫기 후 새 입력으로 재개한다.

## Sound: 연결 완료

- Master / BGM / SFX 음량 및 Mute all. 변경 즉시 적용.
- localStorage pawhaven.sound.v1에 자동 저장하고 새로고침 시 복원한다. 저장소 차단·손상 시 세션 설정/기본값으로 동작한다.
- Master는 @pixi/sound의 전체 음량과 Web Audio Master gain에 연결한다.
- BGM / SFX는 Web Audio의 분리된 gain bus에 연결한다. 미리듣기로 각 채널의 음량을 확인할 수 있다.
- 정식 BGM 파일은 아직 없으며 BGM 미리듣기는 짧은 합성 멜로디다. 자동 배경음 루프는 추가하지 않았다.
- UI 열기 및 점프/대시/공격이 실제 허용된 경우 짧은 합성 효과음을 재생한다. 무시된 입력이나 일시정지 중에는 재생하지 않는다.
- 사용자 입력 후 오디오를 시작한다. 브라우저 제한/오디오 미지원 시 게임은 계속 실행한다. 페이지 숨김 시 오디오 suspend, 최종 종료 시 정리.

## Account: Guest

현재 PawHaven에는 Supabase SDK·프로젝트 설정·로그인 서버가 없다. Guest 상태와 비활성 Login 버튼을 표시한다. 실제 로그인·로그아웃·클라우드 저장·기기 간 동기화는 연결하지 않았다. 이후 대상 Supabase 프로젝트와 로그인 방식이 정해지면 별도로 연결한다. 다른 프로젝트의 자격 증명을 가져오지 않는다.

## 조작·화면·언어·정보 탭 및 클릭 수정

- Controls: 조작 UI 크기 80~120%, 왼손잡이 좌우 배치 전환, 지원 브라우저에서 진동. 키보드 조작 안내.
- Display: 픽셀 효과/대시 잔상 표시 및 부드러운 카메라 추적을 각각 켜고 끈다.
- Language: 한국어 / English. 기본은 기존처럼 English이며 설정 변경 즉시 팝업·로비·게임·꾸미기·타이틀·완주/출발/도착 문구에 반영한다. 화면 전환 후에도 같은 언어를 사용한다.
- About: Paw Haven 이름, 현재 프로토타입 버전, 짧은 게임 소개.
- pawhaven.settings.v1에 조작·화면·언어 설정을 저장한다. 기존 사운드 저장 키는 유지한다.
- 번역 사전/DOM 바인딩: src/settings/i18n.ts. 코드용 액션/아이템 ID는 번역하지 않는다.
- Settings를 일반 click으로 연다. pointerdown에서 오버레이를 띄우면 손을 뗄 때 새 배경으로 클릭이 전달될 수 있던 경로를 제거했다.
- 배경 닫기는 배경에서 직접 pointerdown과 pointerup을 한 경우만 처리한다. 단독 click/pointerup은 무시하며 ×/Escape 닫기도 유지한다.
- 테스트 33개: 설정 6개 탭, 한영 즉시 전환과 저장, 조작/화면 옵션 적용, 열린 뒤 손 떼기에도 팝업 유지, 의도적인 배경 탭 닫기를 포함한다. 실기기 브라우저 시각·터치 재확인은 별도 필요하다.
