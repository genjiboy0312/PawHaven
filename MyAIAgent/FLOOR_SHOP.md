# Lobby Floor Shop (2026-10-29)

- 상점 → 로비 → 바닥을 기존 공통 구매 확인창·재화 RPC·상태 구독으로 연결했다. 기본 정원 잔디(index 0)만 무료다.
- 모래(1), 안개빛(2), 라벤더(3), 봄 모래(4)는 각 200 Coins, 1회 구매 후 수량 소모 없이 교체한다. 기존 1–3은 색상 프로토타입을 유지한다.
- 봄 모래는 `Resources/Cherry_Terrain_soil.png` / `public/assets/course/cherry-soil.png`를 재사용한다. 신규 이미지 생성·편집·복제 없이 loadHome에서 같은 텍스처를 로드한다.
- LobbyMap의 기존 바닥 레이어를 TilingSprite로 사용한다. 기본 잔디는 기존 전체 이미지 비율로 표시하고, 봄 모래는 160 world units 간격으로 반복해 픽셀 밀도를 유지한다. 배경·배치·캐릭터 좌표는 변경하지 않는다.
- 상점의 바닥 카드는 배경과 같은 2열 레이아웃을 재사용한다. 이름·가격·보유 표시·미리보기를 제공하며 구매로 실제 홈이 바뀌지 않는다.
- 홈에는 보유한 바닥만 표시한다. 구매만으로 자동 적용하지 않는다. HomeCatalog의 상품 규칙과 HomeState의 소유권 검사를 재사용하고 로컬 저장도 유지한다.
- 과거 무료 색상 선택값만으로 유료 바닥을 소유 처리하지 않는다. 미구매 선택은 기본 잔디로 대체한다. 계정 소유권 로딩 중에는 기본 표시, 응답 후 observer의 reconcileOwnership으로 정상 구매 선택값을 유지한다.
- 서버 저장 trigger·친구 홈 방문에서 owned_floor로 소유권을 검사한다. homeFloorShopReady가 없는 이전 서버에서는 바닥 구매를 비활성화한다.

## SQL
쿼리 이름: **Lobby Floor Shop**
파일: `supabase/migrations/202610290032_lobby_floor_shop.sql`. 031 이후 적용한다. 사용자 실행 확인은 대기 중이다.

Floor 카테고리·인덱스 0–4·보유 상한 1을 추가한다. 서버 가격·지갑 잠금·동일 요청 재시도·계정 격리·재구매 제한을 기존 buy_home에서 처리한다. 기존 펫·하늘·가구·패스·싱글/멀티 보상·일일 퀘스트·우편 함수는 유지한다. 우편/쿠폰의 바닥 지급 확장은 이번 범위에 포함하지 않는다.
