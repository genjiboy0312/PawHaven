# 싱글 맵 달성 목표 (2026-10-22)

## 승인 범위
- 맵마다 완주(finish), 낙하 없는 완주(noFalls), 목표 시간 내 완주(time) 세 가지를 둔다.
- CourseCatalog.goalSeconds에 연습장 12초·정원 30초·숲 40초를 정의한다. 기존 안내 시간의 상한이며 밀리초 단위 기록으로 경계를 포함해 판정한다.
- 맵 선택 요약과 맵 카드에 작은 발바닥·목표 문구 세 개를 표시한다. 달성 여부는 색과 접근성 문구로 구분한다.
- 결과창은 누적 달성 상태를 보여주고 이번에 새로 달성한 목표만 따뜻한 노란색과 NEW / 새 달성으로 강조한다. 최고 기록 경신 표시는 별도로 유지한다.
- 기존 CSS 발바닥(race-course-paw), 크림 패널, 폰트와 영어/한국어를 재사용한다. 새 이미지·효과음·라이브러리·SQL·재화 보상은 없다.

## 상태와 저장
- SingleRecords.complete(map, seconds, falls)가 기록과 목표를 한 번에 갱신하고 newBest/goals/newGoals를 반환한다. PlayScene의 기존 완료 1회 가드를 사용한다.
- 빠른 기록이 아니어도 낙하 없는 완주 등 새 목표를 얻을 수 있다. 이미 얻은 목표는 느린 기록이나 재낙하로 사라지지 않는다.
- 유효한 완주 시간과 0 이상의 정수 낙하 횟수만 반영한다. 중도 이탈·재시작·미완주는 판정하지 않으며 멀티 순위·경기 보상도 변경하지 않는다.
- 기존 record(map, seconds)의 최고 기록 boolean API는 호환 유지한다. 낙하 정보를 받지 않은 기록에서는 noFalls를 추정하지 않는다.
- 기존 저장 키 pawhaven.single-records.v1을 유지하고 값의 형식을 version:2, times, goals로 확장한다. 예전 version:1 최고 기록으로 확인할 수 있는 완주·시간 목표만 복원한다. 낙하 없는 완주는 새 플레이에서 확인한다.
- 기존 AccountStorage를 사용하므로 게스트/계정별로 같은 기기에 저장된다. SingleRecords는 원래 클라우드 스냅샷 대상이 아니며 이번에도 기기 간 동기화나 서버가 검증하는 업적을 추가하지 않는다. 로그인 계정의 꾸미기·재화 저장과 분리한다.
- 저장이 막히면 메모리에서 유지한다. 보상 권한으로 사용하지 않는 로컬 프로토타입 기록이다.

## 컴포넌트와 검증
- singleGoals(map, earned, fresh)는 공통 순서·라벨·시간 기준의 순수 DOM 컴포넌트다. 맵 메뉴와 결과창에서 재사용하고 기존 언어 변경 옵저버가 다시 그린다. 새 타이머나 전역 이벤트는 없다.
- 검증: 시간 경계, 느린 무낙하 기록, 중복 달성 금지, 누적 보존, 이전 저장 호환, 잘못된 입력·저장 차단, 반환 배열 변경 방어, 계정 분리, 맵 카드 표시, 결과 1회 제출·새 목표 강조·언어 전환.
- 자동 테스트 189개·타입 검사·빌드 통과. 실제 모바일에서 카드·결과창의 글자 크기와 스크롤은 별도 확인 대상이다.
