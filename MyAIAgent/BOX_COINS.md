# 상자 코인과 획득음 (2026-10-28)

- 최종 검증: 전체 323개 테스트·타입 검사·프로덕션 빌드 통과. 실제 Web Audio에서 저장된 음소거/sfx 0으로 첫 재생한 경우와 실행 중 설정 변경 모두 확인했다.

- 기존 나무 상자/금색 코인 텍스처를 재사용한다. 상자가 처음 broken 상태로 바뀌면 코인 1개를 즉시 집계하고, 같은 코인 Sprite가 위로 튀어 캐릭터 쪽으로 흡수되며 사라진다. 다시 공격하거나 낙하 후 돌아와도 같은 상자에서 다시 지급하지 않는다. 새 런은 초기화한다.
- CoinCollection은 일반 배치 코인과 상자별 코인을 같은 items/collected로 관리한다. 상자 코인은 파괴 전 숨기고 일반 접촉으로 수집하지 않는다. DummyRun의 기존 고정 시간 공격/수집 경로를 사용한다. CourseCoinsView는 상태만 관찰하며 0.18초 상승 + 0.32초 흡수/축소/페이드로 표현한다. 효과 끄기에서는 즉시 숨기지만 집계/획득음은 유지한다. 크기 변경이나 반복 render는 소리를 다시 재생하지 않는다.
- 같은 프레임의 새 수집은 한 번의 획득음으로 묶는다. 일반 코인도 동일한 소리를 쓴다. 기존 AudioSystem에 coin 타입과 1046.5/1568Hz 두 sine 음(간격 0.055초, 각 0.18초)을 추가한다. 기존 master/sfx/음소거/가시성/정리 경로를 재사용하고 별도 음원·타이머를 만들지 않는다. 첫 AudioContext 생성 때도 저장된 gain 값을 즉시 설정해 음소거 상태에서 첫 소리가 잠깐 새지 않게 한다. 코인으로 새 진동을 추가하지 않는다.
- 총 수집량/완주 지급/일일 수집 퀘스트에 상자 코인을 포함한다. 공통 courseCoinLimit은 맵 코인 개수 + 타깃 개수. Practice 8/Garden 12/Forest 14/Crossroads 15, 최대 완주 보상은 10+15=25코인이다. Game은 boxCoinRewardsReady 플래그가 있는 서버에서만 상자 코인을 활성화하며 게스트는 바로 사용한다. 구형 서버에서는 기존 코인/상자 파괴를 유지한다. 아트가 없는 독립 씬에서는 보이지 않는 상자 코인을 지급하지 않는다.
- SQL 이름 **Box Coin Drops and Rewards**. 파일 `supabase/migrations/202610280026_box_coin_rewards.sql`. Daily Coin Collector Quest(025) 이후 실행한다. 기존 런/경기 영수증은 보존하고 수집/보상 상한 제약만 15/25로 확장한다. private course_coin_limit을 싱글/멀티 보상에서 공유한다. 최초 승인된 수집량만 일일 퀘스트에 합산하며 기존 중복 지급 방지를 유지한다. 이 문서 작성 시 실서버 실행 완료 응답은 아직 받지 않았다.
- 검증: 30/60/120 FPS에서 상자당 1회·재공격/낙하 중복 제외·새 런 초기화, 숨김→상승/흡수→숨김, 반복 update/resize 획득음 중복 제외, 효과 끄기, 공유 Texture 보존, 구형 서버 비활성화를 확인했다.
