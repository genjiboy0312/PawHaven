# 로비 생활 시스템 1차 (2026-10-17)

## 구현 범위
- 큰 말풍선 하나 안에 힐링 대사와 하트/음표를 함께 표시한다. 재터치 시 내부 기호가 바뀌며 작게 튀고 몸체 이모션이 다시 시작한다. 문구·읽기 시간은 유지한다. 별도 작은 반응 말풍선은 제거했다.
- 로비에서만 발 기준점이 가로 여백 안, 세로 화면 62~86%의 바닥을 산책한다. 위아래 이동 속도는 가로의 65%로 완만하게 한다. 몸체 배율은 그대로이며 원근 크기 변화는 추가하지 않는다.
- 오른쪽 아래 Play 버튼 쪽은 비워두고, 해당 모서리를 지나는 경로에는 중간 경유점을 둬 갑자기 위치를 보정하지 않는다. 상단 메뉴와 배경까지 올라가지 않는다.
- 기존 Idle/산책/쉬기/잠들기/관찰/점프/착지/이모션 상태와 환영·일시정지·터치 보호를 재사용한다. 플레이 씬의 물리/카메라/스케일에는 영향이 없다.

## 쿠션
- Furniture option 4인 설치 개체가 쿠션이다. 기본 로비에 임의로 추가하지 않는다. Home에서 설치해야 한다.
- 휴식·수면을 선택하면 가까운 사용 가능한 쿠션을 찾아간다. 오랫동안 선택되지 않으면 약 14초 이후 다음 Idle에서 방문을 시도한다.
- 목표는 쿠션 중심 x, 배치 원점 y-8px이다. 도착하면 REST → SLEEP → IDLE로 이어지고, 같은 쿠션을 즉시 반복하지 않도록 20초 대기한다.
- 현재 1마리 로비 기준이며, 메뉴에 가려지는 쿠션과 바닥 범위 밖 대상은 방문하지 않는다. 쿠션이 없으면 일반 자율 생활을 계속한다.
- 걷는 중 쿠션이 이동하면 새 좌표를 목표로 한다. 쉬는 중 쿠션이 이동하거나 회수되면 현재 자리에서 쉬기를 중단한다. 접근이 25초를 넘으면 Idle로 복구한다.
- 쓰다듬으면 쿠션 사용을 즉시 끝내고 같은 자리에서 교감한다. 힐링 대사가 끝나고 마지막 터치 모션까지 마치면 자율 행동을 재개한다.
- 현재 전용 누운 시트는 생성하지 않았다. 기존 Idle 시트의 호흡·수면 z z 표현을 재사용한다. 가구를 피해 가는 전체 길찾기/충돌, 여러 동물의 자리 예약은 후속 범위다.

## 겹침과 상태 연결
- PixiJS RenderLayer로 가구·캐릭터·그림자를 같은 깊이 순서에 놓는다. 논리 부모는 유지하되 발 기준점이 아래일수록 앞에 그린다.
- 쿠션 사용 중 캐릭터는 쿠션보다 살짝 앞, 그림자는 뒤에 둔다. 말풍선과 z z는 별도 표현 레이어에 둬 가구에 가리지 않게 한다.
- HomeState.revision이 선택/배치/이동/회수 저장 시 증가한다. 로비는 변경 시에만 맵과 쿠션 목록을 갱신하며 개체 ID를 유지한다.
- Home 저장 형식과 기존 프리셋은 유지한다. 로비로 재진입 시 저장된 꾸미기를 읽고 활동 상태는 새로 시작한다.

## 후속 기획
- 간식은 이번 구현에 포함하지 않는다. 기본 간식은 플레이/퀘스트, 선택형 보상 광고는 추가 무료 획득, 특별 간식은 Shop 판매 후보로 둔다.
- 보상 광고는 완료 확인 후 지급하고 취소/로딩 실패는 횟수 차감 없이 복귀한다. 일일 횟수/보상량과 상품 가격은 추후 결정한다.
- 간식·광고 보상·닉네임 변경권의 실제 지급/차감은 계정·DB/서버 검증 단계에서 진행한다. 배고픔·미접속 불이익은 넣지 않는다.

## 검증
- 자동 테스트 62개, 타입 검사와 빌드. 30/60/120 FPS 양축 산책/영역/이동 속도 제한, 가까운 쿠션 선택/도착/휴식/수면/대기, 이동/회수/쿠션 없음, 코기·명랑이 깨우기/단일 말풍선, 실제 로비 레이어 순서/일시정지/동적 Home 갱신/자원 정리를 포함한다.
- 브라우저 도구가 Windows sandbox helper 오류로 시작하지 못했다. 실제 모바일의 말풍선 배치/쿠션 위 자세/겹침/터치 느낌은 사용자 확인이 필요하다.
- 참고: [PixiJS Render Layers](https://pixijs.com/8.x/guides/concepts/render-layers), [Container](https://pixijs.com/8.x/guides/components/scene-objects/container).
