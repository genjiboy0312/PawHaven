# Shop / Quest 시즌패스 프로토타입

## 흐름

- 로비 Shop → Shop 씬, Quest → 중앙 팝업. Friends는 별도 더미 팝업을 연다. 상세: [FRIENDS.md](FRIENDS.md).
- Shop 탭은 Style / Pass. Style은 기존 코기 미리보기·SVG 아이템·4열 인벤토리와 옅은 바닥 그림자를 재사용한다. 새 이미지 생성 없음.
- Style 하위 Hat / Body / Acc / Etc 각각 20개. 선택 시 미리보기 이모션, 구매 시 테스트 코인 차감 및 Owned 표시. 실제 착용 아트는 계속 미구현이다.
- 초기 테스트 코인 1000개, 분류별 1번 아이템은 기본 보유. 구매한 아이템만 꾸미기 인벤토리에 표시한다. 기존 미보유 더미 선택값을 담은 프리셋은 불러올 때 현재 선택만 0으로 정리하고 저장본은 보존한다.
- 가격은 75~150 테스트 코인. 중복 구매·잘못된 상품·코인 부족은 차감하지 않는다.
- Pass에는 시즌명·테스트 시즌 안내·경험치·무료/프리미엄 5단계 보상 미리보기와 테스트 무료 해금 버튼을 둔다. 실제 가격·결제·만료일은 없다.
- Shop의 보상 보기 → Quest Season Pass, Quest의 상점으로 이동 → Shop Pass. 한 상태를 공유한다.
- Quest는 Daily / Weekly / Season Pass 탭. Daily는 교감·완주 퀘스트를 제공하고 Weekly는 준비 중 안내를 표시한다. Season Pass는 실제 테스트 보상 수령 가능.

## 시즌 진행과 데이터

- 코스를 완주하고 Victory 뒤 로비로 돌아올 때 경험치 +100. 1단계에서 시작하며 400XP/5단계에서 제한한다.
- 단계별 무료 보상 = 단계×20 코인, 프리미엄 보상 = 단계×40 코인. 해당 단계에 도달해야 하며 프리미엄은 테스트 해금 후 수령 가능하다. 보상은 트랙·단계별 한 번만 지급한다.
- ShopState는 잔액·소유 상품·패스 보유·XP·수령 목록을 pawhaven.shop.prototype.v1에 저장한다. 새로고침 시 복원, 저장소 차단 시 세션 내에서 동작한다.
- 서버·실제 계정·다른 기기와 동기화하지 않는다. 클라이언트 테스트 상태이며 실제 유료 구매/보상 권한 검증으로 사용하면 안 된다.
- Quest 팝업은 배경 UI inert/일시정지, 포커스 이동·복원, ×/Escape/직접 배경 탭 닫기를 지원한다.

## 일일 퀘스트 1차 (2026-10-17)
- 오늘의 교감: 로비 동물을 3회 쓰다듬기 → 50코인. 가벼운 산책: 플레이 코스 1회 완주 → 100코인. Quest → Daily에서 진행도·보상·수령 버튼을 표시한다.
- 허용된 로비 터치만 집계하고, 집계된 교감 사이에는 10초 간격을 둔다. 빠른 재터치는 기존 이모션/말풍선 반응을 유지하지만 퀘스트 수량은 올리지 않는다. 마지막 집계 시각도 저장해 새로고침으로 간격을 우회하지 않는다.
- 완주는 기존 Victory/로비 복귀 콜백에서 시즌 XP와 함께 기록한다. 낙하/실패/중도 이탈은 집계하지 않는다. 시즌 XP가 400이어도 일일 완주는 집계한다.
- 목표 달성 전 수령 불가, 달성 후 직접 수령, 수령 후 중복 차단. 지급 코인은 기존 Shop 잔액에 합쳐지며 아이템 구매에 바로 쓸 수 있다.
- 기존 pawhaven.shop.prototype.v1 안에 daily {day, pet, run, claimed, lastPet}를 추가했다. 진행·수령 플래그·코인을 같은 데이터로 저장한다. 기존 구매/패스/코인 저장을 보존한다.
- 날짜는 기기 로컬 시간 자정 기준이다. 다음 접속/행동/Quest 열기 시 초기화하며, 팝업이 열린 동안에도 1초마다 날짜 변경만 확인한다. 닫기/종료 시 타이머를 정리한다. 시계가 이전 날짜로 돌아가면 직전 날짜를 다시 열지 않는다.
- 카운터·수령값·날짜를 검증하고 저장소 차단 시 세션 내 동작한다. 프리셋과 마지막 강아지/꾸미기 저장은 유지한다. 서버 시간/계정·다른 기기 동기화는 후속 범위다.
- 한영 문구와 기존 Weekly/Season Pass 탭·팝업 일시정지·포커스 복귀를 유지한다. 새 이미지 없이 단순한 두 행 UI를 사용한다.
- 자동 테스트 67개·타입 검사·빌드: 10초 집계 간격·재접속·보상 중복 방지·자정/시계 역행·기존 데이터·손상/저장 차단·XP 상한·코인 구매, 실제 로비 입력/Quest 수령·번역·정리, 실패→재시도→완주 경로를 포함한다.
- 실제 브라우저/모바일의 최종 UI·터치 느낌은 별도 확인이 필요하다.

## 완료 보상 알림 및 코인 표기 (2026-10-17)
- 받을 수 있는 Daily 또는 Season Pass 보상이 있으면 로비 Quest 원형 아이콘을 금색으로 강조하고 ! 배지를 붙인다. 접근성 이름에도 보상 수령 가능 상태를 반영한다.
- Quest 내부의 Daily/Season Pass 탭에 보상 점 표시. Daily 수령 버튼과 수령 가능한 패스 보상은 금색이며, Daily 수령 완료 버튼은 차분한 회색으로 구분한다.
- 보상 수령·다음 단계 해금·날짜 변경·재진입 후 현재 상태로 계산한다. 모두 수령하면 알림이 사라진다. 초기 무료 패스 1단계도 미수령 보상이므로 알림 대상이다.
- Shop 상단 잔액은 테스트 코인 대신 Coins / 코인으로 표시한다. 프로토타입 데이터/시즌 테스트 안내는 유지한다.
- 테스트 68개·타입 검사·빌드: 알림 생성/모든 보상 수령 후 해제, Daily 버튼/탭 상태, Shop 잔액 라벨을 검증했다.
