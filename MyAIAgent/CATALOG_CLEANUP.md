# Resource-backed Catalog Cleanup

2026-10-30 사용자 요청: 꾸미기·로비의 준비 중/더미 항목 제거, 꾸미기 기타 탭을 말풍선으로 변경.

## Shared catalog

- 의상은 기존 `outfitReady`를 사용하는 `outfitItems(category)`로 실제 WEARABLES/말풍선 리소스만 표시한다. 산타모자(Hat:1), 검정 탑햇(Hat:2), 빨간 나비넥타이(Acc:2), 하늘색 구름 말풍선(Etc:2)을 유지한다.
- 상의(Body)는 꾸미기·상점 메뉴에서 제외하고 모자·장식·말풍선만 표시한다. Body 저장 키는 기존 프리셋 호환성을 위해 유지한다. 이펙트는 실제 아이템이 추가될 때 표시하며 후광/이동 발자국 장착을 구분한다. 캐릭터 인벤토리는 실제 보유 리소스와 해제 버튼만 표시한다.
- 꾸미기/꾸미기 상점의 Etc 라벨만 한국어 '말풍선', 영어 'Speech Bubbles'로 바꾼다. 저장·구매·프리셋의 Etc 키와 홈 기타 탭은 유지한다.
- 이미지가 없는 펫 종류의 준비 중 탭·카드는 숨긴다. 실제 로드된 강아지·고양이 목록을 사용한다.
- 홈은 `HomeCatalog.HOME_READY_ITEMS`와 `homeItemReady`를 상점·인벤토리·배치 조작·LobbyMap에서 공유한다.
  - Background: 0~4 모두 유지.
  - Floor: 기본 잔디(0), 돌길(2), 봄 모래(4).
  - Furniture: 방석(4), 펫소파(5), 펫하우스(6).
  - Etc: 울타리(4), 초록 나무(5), 벚꽃 나무(6), 상자(7).
- 임시 도형 가구/꽃/돌/램프와 단색 바닥(1,3)은 목록·배치 화면에 표시하지 않는다. 과거 구매·저장 데이터는 지우지 않으며, 해당 바닥의 화면 표현만 기본 잔디로 대체한다. 새 실제 리소스를 연결하면 공통 카탈로그에 등록한다.

## Scope and verification

추가 SQL·새 이미지 없음. 기존 구매/착용/프리셋/드래그/보유 수량 처리와 승인된 픽셀 이미지·Jua를 재사용한다. 브라우저에서 실제 리소스로 모자 2, 장식 1, 말풍선 1, 하늘 5, 바닥 3, 가구 3, 기타 4의 목록과 더미 미표시를 확인했다. 꾸미기 말풍선 탭은 해제(0)와 실제 보유 구름(2)을 표시한다. 더미 배치를 숨겨도 저장 내역이 변경되지 않는 테스트를 추가했다.

갈색 가방은 향후 장식 분류의 작은 배낭으로 어깨 뒤 등 위쪽에 장착하는 구상이다. 시안: [BROWN_BACKPACK_PROTOTYPE.md](BROWN_BACKPACK_PROTOTYPE.md). 이번 작업에는 리소스 제작·장착 추가를 포함하지 않는다.
