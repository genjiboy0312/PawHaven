# 힐링 대사와 터치 (2026-10-17)

## 현재 구현
- 코기·명랑이 로비 터치에 큰 말풍선, 한영 랜덤 대사 6쌍, Emote와 하트/음표를 함께 표시한다.
- 수락된 터치마다 대사와 기호를 함께 바꾸고 모션을 처음부터 재생한다. 직전 대사는 제외한다. 0.8초 이내 재입력은 모두 무시한다. 새 대사는 길이에 따라 4.5~7초 표시한 뒤 자율 행동으로 돌아간다.
- 점프/착지도 터치로 중단하고 대화할 수 있다. 최초 환영 연출, 수동 모드와 팝업 일시정지 중에는 교감을 받지 않는다. 일시정지 중 대사와 터치 쿨다운도 멈춘다.
- 로비의 실제 터치 입력은 강아지 위치를 따라가는 투명 DOM 버튼이다. LobbyHud.placePet이 논리 좌표를 퍼센트로 변환하므로 화면 크기/세로 회전에도 같은 좌표계를 따른다. 메뉴는 이 영역보다 위에 표시한다. pointerdown으로 즉시 반응하며 키보드 click도 지원한다.
- 로비 생성 때마다 버튼/리스너를 새로 만들고 파괴 시 AbortController로 해제한다. Play 승리 후 새 로비에서도 캔버스 이벤트 판정에 의존하지 않고 입력받는다. 이전 버튼은 새 동물에 영향을 주지 않는다.
- 몸체 메타데이터(명랑이) 또는 Texture.trim(코기)의 클립별 실제 배율과 양방향 범위를 합친 일정한 사각형을 쓴다. 프레임마다 줄어들지 않고 점프 높이를 따라간다. 최소 몸체 코기 80×96, 명랑이 120×128; 사방 여유 각각 40/56 논리 px. 대사·모자는 계산에서 제외하고 승인된 그림/배율은 유지한다.
- 대사는 의미 단위 줄바꿈과 단어 단위 자동 줄바꿈, 18px 글자/25px 줄 높이/272px 내용 폭을 쓴다. SpeechBubble은 흰 둥근 상자, 회색 테두리와 꼬리를 유지하고 화면 경계를 보정한다.
- 언어 변경은 같은 문장의 번역과 남은 시간을 유지한다. Daily 교감 카운트의 별도 10초 제한은 유지한다.
- 로비 Character / Home / Quest / Friends / Shop / Settings / Play에 공통 클릭음을 연결했다. Settings는 중복 재생하지 않도록 open(false)를 쓰고 게임 Settings는 기존 open()을 쓴다. 음량/음소거 설정은 AudioSystem을 그대로 따른다.

## 계정·닉네임과 변경권
- Settings → Account의 최초 무료 닉네임 설정은 구현됐다. 이후 변경권 사용은 후속 기획이며 아직 구현하지 않았다.
- Shop 판매 및 이벤트 보상으로 변경권을 공급할 수 있다. 가격/재화는 추후 결정한다.
- 변경 확정 전에 새 닉네임과 변경권 소모를 안내한다. DB/서버에서 최초 설정 여부·변경권 수량·변경 처리를 검증한다.
- Google/이메일 로그인과 계정 프로필 닉네임을 사용한다. 임시 이름이나 가짜 변경권 기능은 넣지 않는다. 닉네임 대사 연결은 아래 기록을 따른다.
- 말풍선 스킨은 이후 기본/파스텔/구름/발바닥/시즌 등의 외형으로 확장할 수 있다. 현재 스킨 판매/선택 UI는 추가하지 않는다.

- 표시할 때마다 현재 닉네임을 확인해 최초 설정/로그아웃/계정 전환을 반영한다. 공백만 있거나 서버 닉네임 규칙(2~16자 한글·영문·숫자·밑줄)에 맞지 않으면 이름 없는 문구로 복구한다.

- 터치 쿨다운·표정·퀘스트 집계·말풍선 외형은 기존 동작을 사용한다. DB migration은 필요하지 않다.
- 추가 검증: 일부 대사만 개인화, 한영 전환, 미설정/잘못된 이름 폴백, 코기·명랑이 긴 이름 보존/터치 쿨다운, 실제 AccountService 닉네임 설정→로그아웃→다른 계정 반영. 실기기 말풍선 배치는 별도 확인 대상이다.
