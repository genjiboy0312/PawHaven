# 경쟁맵용 피격 반응 준비 (2026-10-23)

## 적용 범위
- 사용자는 기존 맵에는 어울리지 않으므로 기능만 개발하고 새 경쟁맵에서 적용하도록 요청했다.
- garden / practice / forest 모두 CourseCatalog.playerCombat=false다. 기본 DummyRun도 비활성이며 PlayScene은 맵 설정과 멀티 조건을 모두 만족해야 활성화한다. 기존 박스 공격은 유지한다.
- 이번 작업은 **검증된 피격 이벤트를 받은 뒤의 반응 컴포넌트**다. 공격 범위 판정·상대에게 피격을 전달하는 서버 RPC·원격 캐릭터의 피격 이벤트 수신은 아직 연결하지 않았다. 경쟁맵을 추가할 때 함께 구현해야 하며 플래그만 켜서 출시하지 않는다. 현재 SQL 추가는 없다.

## 재사용 구조
- src/game/HitReaction.ts: 렌더러/네트워크/타이머와 독립된 상태 컴포넌트. 보호 시간·초기 플래시·감쇠 밀려남과 순번 중복 방지를 담당한다.
- src/game/DummyRun.ts: receivePlayerHit로 반응을 받아 기존 세분화 물리 업데이트와 수평 벽 충돌에 밀려남을 합산한다. motionVelocity는 송신 pose의 속도에도 반영한다.
- src/animals/HitReactionEffect.ts: 짧은 흰색 플래시와 옅은 보호 깜빡임. 기존 effects.attack 텍스처를 재사용하고 새로운 이미지를 만들지 않는다. 몸체·모자 크기 및 동작 애니메이션을 바꾸지 않는다.
- src/game/scenes/PlayScene.ts: 활성 맵에서만 표시 컴포넌트를 생성한다. receivePlayerHit는 멀티·출발 후·일시정지 아님 조건을 검사하며, 실제 이벤트 공급은 미래 경쟁맵의 검증된 서버 경로에 연결한다.

## 초기 수치와 동작
- 보호 1.2초. 보호 중 후속 피격은 무시하고 보호 시간을 연장하지 않는다.
- 흰색 플래시 0.12초, 재사용 타격 텍스처 0.22초. 보호 중 alpha 0.74~1 범위로 약하게 변화한다. 효과 끄기에서는 플래시/점멸을 없애고 일정한 옅은 표시만 남긴다.
- 수평 밀려남은 명목상 64월드 단위에 이동 스케일을 적용하고 0.32초 동안 감쇠한다. 수직 속도·점프 높이를 바꾸지 않으며 벽과 맵 양끝을 통과하지 않는다.
- 입력을 잠그는 경직은 없다. 기존 대시 중 피격되면 그 대시만 중단하며 쿨다운은 유지한다. 이동·점프·공격 가능 여부는 기존 규칙을 그대로 따른다.
- 리스폰·결승·재접속 복원 시 반응을 초기화한다. 순번 기준은 보존해 예전 피격의 재전달을 막는다. 라운드가 바뀌면 새로운 씬/컴포넌트를 사용한다.

## 경쟁맵 연결 시 할 일
1. 서버에서 해당 맵/라운드/참가 상태와 공격 시점·거리·방향·높이·보호 시간을 판정한다. 클라이언트의 적중 주장만으로 상대를 밀지 않는다.
2. 대상별 증가하는 안전 정수 sequence와 서버가 결정한 수평 direction(-1 또는 1)을 전달한다. 보호 중 무시된 이벤트도 순번을 소비해 지연 재전달을 막는다.
3. 자기 캐릭터에는 receivePlayerHit를, 원격 캐릭터에는 같은 반응 표시를 연결한다. 위치는 기존 pose/RemoteMotion 경로를 재사용하며 실제 두 기기의 지연·중복·재접속을 검증한다.
4. 그 후 경쟁맵의 playerCombat만 활성화한다. 기존 세 맵의 false는 유지한다.

## 검증
