# 코인 수집전

- 플레이 → 싱글 → 코인 수집전 탭을 선택하고 플레이를 누른다.
- 30초 안에 코인 12개를 모은다. 12개를 모두 모으면 즉시 종료하고, 제한 시간이 끝나면 현재 개수를 점수로 확정한다. 다시 하기는 새 라운드에서 시작한다.
- 계단 서바이벌의 고정 발판과 기존 코인 이미지·소리·획득 판정을 공유한다. 낮은 발판의 코인은 달리며 줍고, 높은 발판 위의 공중 코인은 점프해서 줍는다.
- 점수는 해당 라운드의 HUD와 결과창에서만 사용한다. 레이스 보상, 계정 시간 기록 및 멀티 방 생성은 기존 경로와 분리한다. 서버 마이그레이션은 없다.

## 멀티 코인 수집전

- 멀티 방 만들기 또는 방장의 맵 선택에서 코인 수집전 탭을 사용한다. 서버가 `coinRushReady`를 제공하면 탭이 열린다.
- 기존 로딩 확인과 동시 출발을 사용한다. 게임 시간은 서버 공통 30초이며, 마지막 획득 보고를 받을 수 있도록 결과 확정에 최대 1.2초의 여유를 둔다. 남은 참가자가 모두 12개를 모으면 조기 확정한다.
- 코인 12개의 위치는 동일하고 각자의 로컬 코인만 사라진다. 이동 동기화 요청에 획득한 코인 목록을 비트로 담고, 서버는 인증된 참가자의 현재 라운드에만 합친다. 연결이 복구되면 서버가 확인한 코인을 복원한다.
- 실시간 순위와 결과는 서버가 접수한 점수를 사용한다. 개수 우선, 12개 완수 시 시간 우선, 남은 동점은 공동 순위다. 코인 위치 충돌은 클라이언트에서 계산하며 서버에서 물리를 다시 재현하지 않는다.
- SQL Editor 이름은 **Multiplayer Coin Rush**. `supabase/migrations/202611080041_multiplayer_coin_rush.sql`을 039 이후 적용한다. 수집전 기록은 레이스 완료 시간이나 재화 보상에 쓰지 않는다.
- 로컬 DB에서 독립 획득, 중복 전송, 과거 라운드, 제한 시간, 결과 확정, 응답 유실 복구, 재화 지급 거부를 검증했다. 기존 실시간 순위와 시상대를 재사용한다.
