# Home 로비 꾸미기 프로토타입

2026-10-16. 로비의 Character 오른쪽 Home 버튼으로 별도 HomeScene에 진입한다. 캐릭터 없이 맵만 편집하며 Close로 로비에 복귀한다.

## 현재 동작

- 탭: Background / Floor / Furniture / Etc. 한영 전환 지원.
- 배경·바닥 각 4가지, 가구 None+4가지, 소품 None+4가지. 각 분류는 한 종류씩만 표시한다. 여러 가구 인스턴스는 아직 지원하지 않는다.
- Background 첫 번째: 픽셀 하늘·나무 배경. Floor 첫 번째: 픽셀 잔디. Furniture 마지막: 실제 픽셀 쿠션. 나머지는 기존 색상/도형 더미다. 배경/바닥에 큰 타원형 패치는 없다. 아이템 목록의 작은 그림자는 유지한다.
- Furniture/Etc 목록에서 선택하면 맵에 배치한다. 맵의 해당 오브젝트를 드래그해 재배치한다. 선택한 오브젝트에 옅은 점선 테두리와 Remove 버튼을 표시한다. None 또는 Remove로 제거한다.
- 각각 한 개씩 배치하며 서로 겹쳐도 된다. 동물/가구 충돌이나 동물의 쿠션 사용 행동은 이번 범위에 포함하지 않았다.
- 배치 원점은 맵 너비 10~56%, 높이 62~87%로 제한한다. 물체 크기를 고려해 화면 밖·상단 메뉴·우측 목록 영역을 피한다. 프로토타입의 편집 가능 영역은 목록 왼쪽 바닥이다.
- 마우스·터치 Pointer Capture 사용. 회전된 모바일 화면의 좌표를 역변환한다. 처음 잡은 위치의 간격을 유지하며 한 포인터만 드래그한다.
- 위치는 드롭 시 자동 저장한다. 이동 중에는 저장하지 않는다. 포인터 취소/캡처 상실/포커스 상실/리사이즈/탭·목록 전환/씬 종료 시 진행 중인 미저장 드래그를 취소한다.
- 키보드로 오브젝트 버튼에 포커스 후 방향키로 이동, Delete/Backspace 또는 Remove로 제거할 수도 있다.
- HomeState의 기존 pawhaven.home.v1 저장값에 placements를 추가했다. 이전의 색상/선택값은 유지하며 위치 없는 데이터에는 기본 위치를 적용한다. 좌표 검증·영역 제한·깊은 복사·저장소 차단 폴백을 지원한다. 분류별 위치는 None/아이템 교체 후에도 유지한다.
- 로비와 Home은 같은 상태·렌더러·공용 텍스처를 사용한다. 로비로 돌아오거나 재접속해도 배치가 유지된다. 로비 코기는 자율 행동을 재개하고 첫 환영을 반복하지 않는다. 플레이 코스는 변경하지 않는다.

## 파일과 검증

- src/home/HomeState.ts: 선택/위치 저장, 좌표 제한, 모바일 좌표 변환.
- src/home/LobbyMap.ts: 레이어별 공유 맵 렌더러. src/home/loadHome.ts: 공용 이미지 로딩.
- src/game/scenes/HomeScene.ts: 목록, 드래그, 선택/제거, 입력 정리. LobbyScene.ts와 Game.ts는 같은 맵 상태/텍스처를 전달한다.
- 리소스 경로·제작 도구·최종 프롬프트: [HOME_ART.md](HOME_ART.md).
- 자동 테스트 48개 및 타입 검사/빌드 통과. 기존 기능과 함께 배치 저장/이전 데이터/손상 좌표/저장 차단, 실제 Home 입력의 미리보기와 드롭 저장, 다른 포인터 무시, 회전 좌표, 영역 제한, 취소/리사이즈, 키보드/제거, 배경·바닥 독립 교체, 로비 복원을 확인했다.
- 테스트는 모델과 가짜 DOM 입력 검증이다. 실제 브라우저 도구가 시작하지 못해 PC·모바일 화면의 최종 아트 비율/터치 느낌은 미검증이다.
- 후속 개발 순서: [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md).
