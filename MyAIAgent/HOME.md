# Home 로비 꾸미기 프로토타입

2026-10-16. 로비의 Character 오른쪽 Home 버튼으로 별도 HomeScene에 진입한다. 캐릭터 없이 맵만 편집하며 Close로 로비에 복귀한다.

## 현재 동작

- 탭: Background / Floor / Furniture / Etc. 한영 전환 지원.
- 배경·바닥 각 4가지, 가구 4가지, 소품 4가지. 각 아이템을 프로토타입 기본 수량 3개씩 제공한다. 같은 종류와 서로 다른 종류를 함께 여러 개 배치할 수 있다(최대 가구 12개+소품 12개).
- Background 첫 번째: 픽셀 하늘·나무 배경. Floor 첫 번째: 픽셀 잔디. Furniture 마지막: 실제 픽셀 쿠션. 나머지는 기존 색상/도형 더미다. 배경/바닥에 큰 타원형 패치는 없다. 아이템 목록의 작은 그림자는 유지한다.
- Furniture/Etc 목록에서 선택하면 맵에 배치한다. 맵의 해당 오브젝트를 드래그해 재배치한다. 선택한 오브젝트에 옅은 점선 테두리와 Remove 버튼을 표시한다. Remove는 선택한 개체 하나만 회수하고 해당 아이템의 남은 수량을 1 늘린다. 공용 None 버튼은 제거했다.
- 배치된 각 개체는 고유 ID와 독립 위치를 가진다. 서로 겹쳐도 되며 화면상 아래쪽 개체부터 앞에 그린다. 일반 가구 충돌은 아직 없다. 동물의 쿠션 접근·휴식·수면과 발 위치에 따른 겹침은 [LOBBY_LIFE.md](LOBBY_LIFE.md)에 구현했다.
- 상단에 탭과 가로 스크롤 아이템 목록을 둔다. 배치 원점은 맵 너비 10~90%, 높이 62~87%로 제한해 오른쪽 바닥도 편집할 수 있다. 기존 배치 좌표와 수량 저장 방식은 유지한다.
- 마우스·터치 Pointer Capture 사용. 회전된 모바일 화면의 좌표를 역변환한다. 처음 잡은 위치의 간격을 유지하며 한 포인터만 드래그한다.
- 위치는 드롭 시 자동 저장한다. 이동 중에는 저장하지 않는다. 포인터 취소/캡처 상실/포커스 상실/리사이즈/탭·목록 전환/씬 종료 시 진행 중인 미저장 드래그를 취소한다.
- 키보드로 오브젝트 버튼에 포커스 후 방향키로 이동, Delete/Backspace 또는 Remove로 제거할 수도 있다.
- HomeState는 기존 pawhaven.home.v1 키에 version:2, Background, Floor, items[{id,tab,option,x,y}]를 저장한다. 남은 수량은 3 - 배치된 같은 아이템 수로 계산해 별도로 차감 값을 저장하지 않는다. 이전 단일 배치의 색상·아이템·위치는 개별 개체로 자동 변환한다. 빈 v2 목록을 다시 이전 배치로 복원하지 않는다. 잘못된 ID/중복 ID/아이템/좌표/과도한 배치는 무시하고 영역을 제한한다. 깊은 복사·저장소 차단 폴백을 지원한다.
- 로비와 Home은 같은 상태·렌더러·공용 텍스처를 사용한다. 로비로 돌아오거나 재접속해도 배치가 유지된다. 로비 코기는 자율 행동을 재개하고 첫 환영을 반복하지 않는다. 플레이 코스는 변경하지 않는다.

- src/home/HomeState.ts: 선택/위치 저장, 좌표 제한, 모바일 좌표 변환.
- src/home/LobbyMap.ts: 레이어별 공유 맵 렌더러. src/home/loadHome.ts: 공용 이미지 로딩.
- src/game/scenes/HomeScene.ts: 목록, 드래그, 선택/제거, 입력 정리. LobbyScene.ts와 Game.ts는 같은 맵 상태/텍스처를 전달한다.
- 리소스 경로·제작 도구·최종 프롬프트: [HOME_ART.md](HOME_ART.md).
- 자동 테스트 48개 및 타입 검사/빌드 통과. 기존 기능과 함께 배치 저장/이전 데이터/손상 좌표/저장 차단, 실제 Home 입력의 미리보기와 드롭 저장, 다른 포인터 무시, 회전 좌표, 영역 제한, 취소/리사이즈, 키보드/제거, 배경·바닥 독립 교체, 로비 복원을 확인했다.
- 테스트는 모델과 가짜 DOM 입력 검증이다. 실제 브라우저 도구가 시작하지 못해 PC·모바일 화면의 최종 아트 비율/터치 느낌은 미검증이다.
- 후속 개발 순서: [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md).

## 수량과 여러 개 설치

- 목록 아이콘 오른쪽 아래 숫자는 보유량 중 아직 설치하지 않은 수량이다. 설치 시 3→2→1→0으로 감소한다.
- 0개가 되면 아이콘과 작은 그림자를 흐리게 하고 추가 설치 버튼을 비활성화한다. 숫자 0은 읽을 수 있게 유지한다. 모델에서도 수량 초과를 막는다.
- 목록에서 같은 아이템을 다시 누르면 새로운 개체를 추가한다. 기존 개체를 교체하지 않는다. 새 개체는 바닥의 임시 배치 위치에 놓이고 각자 드래그할 수 있다.
- Remove는 선택한 개체만 제거한다. 수량이 복구되면 목록 버튼과 아이콘도 즉시 활성 상태로 돌아온다.
- 자동 테스트 48개를 갱신해 3개 설치/4번째 차단, 다른 종류의 독립 수량, 복제 개체 개별 이동, 한 개만 회수, 남은 개체/좌표 유지, 재접속/로비 복원, 기존 데이터 변환과 손상 데이터 제한을 검증했다. 실제 모바일 시각/터치 확인은 별도 필요하다.
