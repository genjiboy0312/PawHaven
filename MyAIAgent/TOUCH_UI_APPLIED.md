# 2D 조작 UI·멀티 패널·상점 헤더 적용

## 최신 기준: 펫소파 밀도 (이전 기록보다 우선)
- 사용자 기준은 Resources/Pet_Sofa_Black_White_Prototype.png의 촘촘하고 자연스러운 픽셀이다. 이전의 굵은 도트 확대 방식은 사용하지 않는다.
- 아이콘 32→64격자, 바탕·손잡이 48→96격자, 조이스틱 바닥 64→128격자로 세밀하게 조정했다. 윤곽은 정수 격자로 유지하고 색은 절제된 가까운 단계로 표현한다. SVG의 강제 pixelated 확대는 제거했다.
- 영어 5×7 도트 라벨 확대는 없애고 기존 둥근 폰트로 한영 모두 표시한다. 기존 도트 라벨 원본은 보존하되 사용하지 않는다. 버튼 크기·배치·아이콘과 글자의 좁은 간격·쿨다운·입력 규칙은 유지한다.
- scripts/generate-touch-controls.mjs로 재생성하며 Resources/Control_*와 public/assets/controls에 동일하게 저장한다. 바탕뿐 아니라 img 아이콘 주소에도 버전 20261023c를 붙여 이전 이미지 캐시를 갱신한다.
- 전체 192개 테스트·타입 검사·빌드 통과. Chrome headless 임시 fixture에서 1280×720 영어 조작부, 800×540 한국어 쿨다운 상태를 렌더링해 확인했다. 실제 기기 터치·캐릭터 렌더링·멀티 접속 검증은 아니며 임시 파일/서버는 정리한다.

## 2026-10-23 사용자 피드백 반영 (아래 최초 적용 기록보다 우선)
- 후속 수정: 상점 코인/X 표시 크기를 44~52px에서 28~38px로 축소하고 상단을 7cqh로 조정했다. X의 투명 터치 여유는 별도로 유지한다. 잔액 글자도 10~15px로 줄였다.
- 승인 시안의 도트 글자까지 반영하도록 영어 라벨을 직접 작성한 픽셀 SVG로 표시한다. 실제 번역 텍스트와 접근성 이름은 유지하고 한국어에는 기존 한글 폰트를 사용한다. 조이스틱 네 방향도 도트 심볼로 통일했다.
- 재생성 원본은 scripts/generate-touch-controls.mjs다. 아이콘·색면·영어 라벨을 Resources와 배포 경로에 함께 저장하므로 이후 전체 이미지를 다시 생성할 필요가 없다. 버튼 색면은 48격자, 조이스틱 바닥은 64격자로 도트 간격을 확보했다.
- 매끈한 CSS 원·곡선 아이콘을 계단형 도트 SVG로 교체했다. 아이콘은 32격자, 색면·조이스틱 손잡이는 64격자이며 crispEdges/pixelated를 적용한다. Resources/Control_*와 public/assets/controls에 동일 원본을 보존한다.
- 아이콘은 버튼 높이 19~65%, 라벨은 69%부터 배치해 간격을 좁혔다. 쿨다운에는 아이콘을 줄여 숫자 공간을 확보한다. 기존 컴포넌트·입력·쿨다운 규칙을 재사용한다.
- 상점 패널 시작점은 3cqh, 코인/X는 6cqh로 내려 안쪽에 배치한다. 패널 오른쪽 2cqw, X 오른쪽 4cqw로 여백을 확보하고 최소 터치 크기 44px를 유지한다. 잔액 최대 너비도 패널 폭으로 제한한다.
- 전체 192개 테스트·타입 검사·빌드 통과. Chrome headless 임시 fixture에서 1280×720 조작부와 800×540 상점을 렌더링했다. 패널/코인/X 사각 영역을 비교해 내부 포함과 여백을 확인했다. 실제 로그인·모바일 터치·멀티 접속 검증은 아니다.

## 조작부
- 승인된 Resources/Touch_Controls_UI_Prototype_v3.png를 기준으로 평면 원형 색면·갈색 외곽선·얕은 그림자를 적용했다. Attack은 발바닥만, Dash는 이중 화살표, Jump는 위 화살표다.
- 이미지 시안 v1/v2/v3는 Resources에 모두 보존한다. 실제 아이콘은 직접 작성한 단순 SVG를 Resources/Control_Attack.svg, Control_Dash.svg, Control_Jump.svg에 저장하고 public/assets/controls에 동일 파일을 배포한다. 시안 전체 PNG를 잘라 붙이거나 무거운 텍스처를 추가하지 않는다.
- 기존 발바닥 배치·큰 Jump·좌측 조이스틱·왼손잡이 옵션·조작 크기·키보드 입력을 유지한다. 조이스틱은 반투명 평면 바닥·크림색 손잡이와 좌우 방향 표시를 사용한다.
- ActionButton이 아이콘·번역 라벨·쿨다운 표시를 담당하고 PlayScene의 기존 업데이트에서 상태를 전달한다. 라벨만 번역하므로 아이콘이 텍스트 변경으로 지워지지 않는다. 별도의 타이머·옵저버·네트워크 요청은 없다.
- DummyRun.canJump/canDash/canAttack을 실제 행동과 UI가 함께 사용한다. 규칙과 속도는 유지한다: 공중 대시 금지, 공중 공격 허용, 대시 중 공격/점프 제한, 공격 중 대시 제한. 대시 쿨다운은 기존 0.8초다.
- 대시 테두리 원호가 차오르고 남은 시간을 0.1초 단위로 표시한다. 사용 불가·일시정지·출발 대기에는 실제 버튼을 비활성화한다. 포커스 표시와 reduced-motion 설정을 유지한다.

## 멀티 패널
- 방 만들기 버튼에 일관된 너비·높이와 box-sizing을 적용하고 상단 우측에 맞췄다.
- Previous / Next / 페이지 숫자 / Back을 스크롤 본문 밖의 footer로 옮겼다. 목록만 스크롤하며 페이지 이동과 뒤로 버튼은 패널 하단에 남는다. 페이지 이동은 중앙, Back은 우측이다.
- footer도 기존 busy/재접속 잠금에 포함하고 Back의 복구 중 이동 허용 규칙을 유지한다. 싱글 선택 화면은 기존 좌측 상단 뒤로 버튼을 유지한다.

## 상점
- 제목·코인 잔액·X의 높이와 상단 기준선을 맞췄다. 코인은 X 왼쪽에 간격을 두고 배치한다.
- 헤더 높이와 탭 높이로 상품 영역의 시작 위치를 계산해 작은 가로 화면에서도 겹치지 않게 한다. DOM·구매 확인·재화·소유권·탭 동작은 유지한다.

## 검증
- 전체 테스트 192개·타입 검사·프로덕션 빌드 통과. 실제 입력 제한·공중 공격·쿨다운·일시정지·한영 아이콘 유지, 리소스 원본/배포본 일치, 하단 페이지 이동과 뒤로 동작을 검증한다.
- Chrome headless로 실제 모듈·CSS·폰트를 불러온 임시 UI fixture를 렌더링했다. 멀티 footer가 본문 아래에 분리되고, 작은 가로 창에서 코인/X의 y·높이가 같으며 탭 끝보다 상품 시작이 아래임을 확인했다. 버튼 색·아이콘·배치도 이미지로 확인했다. fixture는 모의 방/빈 캐릭터 프리뷰이며 실제 로그인·멀티 접속 테스트는 아니다.
- 임시 fixture·로그는 정리하고 로컬 서버를 종료한다. 실제 모바일 터치감·두 기기 멀티는 별도 확인 대상이다. SQL·추가 의존성은 없다.
