# 멀티 실시간 잠정 순위 (2026-10-22)

- 경기 우측 상단, 설정·나가기 버튼 아래에 순위·닉네임을 최대 4행으로 표시한다. 본인 행은 기존 연한 초록색으로 구분하며 긴 이름은 말줄임한다.
- 카운트다운 중에는 숨기고 출발 후 표시한다. 본인이 먼저 완주한 뒤에도 남은 참가자의 잠정 순위를 볼 수 있다. 최종 results에서는 숨기고 기존 서버 결과 팝업을 사용한다.
- RaceStandings는 표시만 담당하는 컴포넌트다. 기존 PlayScene 업데이트에서 0.2초 간격으로 계산하며 순서·이름·완주 기록이 바뀔 때만 행 DOM을 갱신한다. 추가 타이머·API·채널·SQL·이미지는 없다.
- 진행 바와 같은 참가자 배열과 화면 좌표를 사용한다. 본인은 현재 물리 x, 상대는 화면에 그리는 보간 x이며 서버가 확인한 완주 기록이 없는 동안 거리 내림차순으로 잠정 정렬한다. 뒤로 이동·체크포인트 복귀도 반영한다.
- 서버 완주 시간이 있는 참가자를 우선 배치하고 시간 오름차순으로 표시한다. 같은 완주 시간은 같은 순위(1, 1, 3)를 준다. 좌표가 도착선을 넘더라도 완주 체크를 만들지 않는다.
- 거리 동률은 직전 표시 순서를 유지한다. 0.2초 갱신으로 매 프레임 순위가 교체되는 것을 피하지만 근접 상황에서는 기기별 보간·통신 지연 때문에 잠정 순위가 다를 수 있다. 최종 순위와 보상은 이 UI가 결정하지 않는다.
- 기존 진행 바와 같이 미완주 이탈자는 제외하고 서버에서 완주 확인된 이탈자는 남긴다. 재접속 중에는 마지막 표시를 흐리게 유지하며 '순위 확인 중'으로 바꾼다. 복구 시 즉시 새 순서를 반영한다.
- 기존 Scene의 언어 변경 옵저버로 영어/한국어 제목과 접근성 이름을 갱신한다. pointer-events:none이므로 조작 버튼을 가로채지 않는다. 완주 대기 결과 패널은 너비를 조금 줄여 오른쪽 순위와 겹치지 않게 한다.
- 검증: 표시 좌표 정렬, 0.2초 제한·같은 순서의 DOM 보존, 동률 안정성, 서버 완주 우선·동률 순위, 도착선 좌표만으로 완주 체크 금지, 재접속 유지·복구·번역, 실제 SQL 경기의 카운트다운 숨김·이동 순위·본인 선완주·최종 결과 숨김.
- 테스트 191개·타입 검사·빌드 통과. 실제 두 기기 순위 반응과 모바일 글자·배치는 실기기 확인 대상이다.
