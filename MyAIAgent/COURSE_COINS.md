# 맵 코인 수집 프로토타입 (2026-10-26)

## 승인 범위
- 4개 코스의 바닥/점프 동선/위쪽 발판에 기존 금색 코인을 배치한다. Practice 7개, Garden 10개, Forest 11개, Crossroads 13개다. 구체적인 위치는 src/game/CourseCoins.ts의 COURSE_COINS를 수정한다.
- 플레이 HUD와 싱글 결과, 멀티 대기/최종 순위 팝업에 본인의 수집 개수/전체 개수를 표시한다. 코인 개수로 순위를 바꾸거나 모두 수집해야 완주하도록 제한하지 않는다.
- 수집 코인은 이번 실행의 기록이다. 상점 잔액·계정 재화·DB·퀘스트·서버 보상에 연결하지 않는다. 기존 완주 보상 흐름은 유지하며 수집 개수를 보상 요청으로 보내지 않는다. 추가 SQL은 없다.

## 자원과 컴포넌트
- 기존 Resources/Gold_Coin_Prototype.png와 배포 사본 public/assets/items/gold-coin.png를 재사용한다. 이미지 생성/편집/새 파일 복사는 하지 않는다.
- loadCourseArt에서 원본을 한 번 로드하고 기존 코인 UI의 추출 범위 Rectangle(357,404,541,541)을 재사용한다. 각 코인의 보이는 크기는 36 world units다. 공용 Texture는 씬마다 파괴하지 않고 Game 종료 시 정리한다.
- CoinCollection/CourseCoin은 Pixi/DOM/재화 시스템에 의존하지 않는 실행별 상태다. DummyRun의 기존 1/120초 물리 단계에서 몸체와 코인 반경 14의 겹침을 판정한다. 공격 이펙트나 상대 캐릭터는 수집하지 않는다.
- CourseCoinsView는 같은 상태를 읽어 코인 위치·표시 여부만 갱신한다. 원본 배치 데이터는 변경하지 않는다. solid를 지정한 코인의 x/height는 해당 발판의 x/top 기준 오프셋이며 Crossroads의 이동 발판 코인도 같이 움직인다.
- 한번 수집하면 사라지고 재접촉/대시/되돌아오기에도 중복 증가하지 않는다. 낙하 후 재출발·같은 씬의 재연결에서는 유지하고 새 게임/재경기는 초기화한다. 멀티 참가자별 수집이므로 상대가 수집해도 내 코인은 남는다. 수집 이벤트를 방송하지 않는다.
- 수집용 텍스처가 없는 독립 테스트/씬 호출에서는 코인 배치도 생략해 보이지 않는 코인을 수집하지 않는다. 시간/목표/체크포인트/기존 조작은 유지한다.

## 표시
- 언어 키 runCoins: Collected coins / 수집 코인. HUD는 기존 진행 표시를 재사용한다. 멀티에서는 중앙 진행 UI와 겹치지 않도록 왼쪽 폭을 제한하고 통신 상태를 아래로 배치한다.
- 멀티 순위 팝업에는 개인 수집 요약만 전달한다. Room/Racer의 서버 데이터, 순위 계산과 기존 우승자 이모션은 변경하지 않는다.

## 검증
- 전체 299개 테스트 통과. 몸체/높이 판정·대시 통과·중복 수집 방지·낙하 후 유지·새 실행 초기화·개인별 상태·이동 발판 추종·공용 텍스처 보존·코인 없이 완주·한영 HUD/결과를 검증했다. 기존 재화/보상 관련 회귀 테스트도 통과했다.
- Chrome/Pixi에서 실제 기존 코인 PNG로 4개 맵의 표시/수집/숨김/HUD와 이동 발판 추종을 확인했다. 싱글 완주 결과와 우승자 캐릭터가 있는 4인 순위 팝업의 개인 수집 개수/패널 높이를 확인했다.
