# README 포트폴리오 화면·서술 기준

2026-11-07. 사용자 요청: 최신 구현을 기획자·개발자/면접관 관점으로 정리하고 명랑이를 사용하는 실제 스크린샷을 첨부한다.

## 반영 범위
- 루트의 기존 README.md를 갱신한다. 다른 프로젝트 Markdown은 계속 MyAIAgent에 둔다.
- 첫 화면은 명랑이 로비, 이어서 3분 체험 경로·주요 화면·현재 기능·설계 결정·검증/실행·프로토타입 한계를 배치한다.
- 기획 의도, 재사용 비용, 상태/서버 책임, 실패 처리와 검증을 설명한다. AI 지원 제작을 명시하며 직접 작성/서버 권위/네이티브 출시/상용 운영 규모를 과장하지 않는다.
- 맵은 현재 싱글 레이스 5 / 멀티 레이스 3 / 공용 서바이벌 2다. 공원 4채널, 친구/차단/홈 방문, 우편/쿠폰, 레벨, 구매/보상, Undo/Redo와 기록 계정 병합을 반영한다.
- 테스트 수치는 기준 코드 bcc324a의 CI 전체 441개다. npm test의 기본 목록과 CI 전체 실행 범위를 구분한다. 이후 테스트/기능이 늘면 수치를 다시 확인한다.

## 스크린샷
- 경로: MyAIAgent/screenshots/. 게임 배포 리소스가 아닌 README 문서용 사진이다.
- 모두 현재 Game/Pixi/DOM/실제 아틀라스와 Jua를 로컬 Chrome에서 1280×720으로 실행해 캡처했다. 이미지 합성·캐릭터 재생성은 하지 않았다.
- 로비: 로컬 기본 코인으로 명랑이(500), 펫 소파(250), 초록 나무(225)를 모델의 실제 구매 경로로 구매하고 기본 방석/울타리와 배치했다. 동물 프레임/시간을 정지해 촬영 구도를 잡았다.
- 캐릭터/서바이벌: 별도 로컬 프로필에서 명랑이·탑햇·스카프를 구매·선택했다. 계단 맵은 실제 키보드 점프 후 높은 발판에 착지한 상태다.
- 홈: 편집 씬은 디자인대로 동물을 표시하지 않는다. 설치 수량과 현재 편집의 Undo/Redo 상태를 캡처한다.
- 멀티: PGlite에서 실제 039까지의 멀티 SQL을 사용했다. 테스트 계정 DemoHost(명랑이 소유)·DemoGuest를 생성하고 실제 create/join/ready RPC와 RoomClient/PlayMenuPopup으로 대기방을 구성했다. 펫 소유권을 먼저 부여한 뒤 캐릭터 저장을 해야 owned_pet 저장 트리거에서 기본 코기로 보정되지 않는다.
- 운영 계정·개인 메시지·사용자 반려견 원본 사진을 촬영 자료로 사용하지 않았다. 공개 README에 로컬 촬영/테스트 계정 조건을 명시한다.
