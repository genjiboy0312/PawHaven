# 안정화 점검 및 M5 교감

기준일: 2026-10-16. DEVELOPMENT_PLAN의 1번 자동 검증과 발견된 입력 문제 수정, 2번 로비 교감을 진행했다.

## 변경

- Background 1~3에 공통으로 포함되던 지평선의 큰 타원형 장식을 제거했다. 앞서 제거한 중앙 바닥 패치와 별개의 도형이다. Background 선택은 배경 색상·해만 변경한다. Floor 선택, 가구·소품과 아이템 아래 작은 그림자는 유지한다.
- 로비 코기의 몸통을 클릭/터치하면 기존 Emote 시트로 1.5초 반응한다. 위치를 유지하고 끝나면 IDLE을 거쳐 자율 생활을 재개한다. 새 이미지/패키지는 추가하지 않았다.
- 반응 중 연속 터치는 타이머를 초기화하지 않는다. 환영·점프·착지 중에는 교감을 시작하지 않는다. 몸통 주변으로 입력 영역을 제한하고 HUD는 DOM 입력으로 분리한다.
- 설정/Quest로 로비가 일시정지되면 교감 입력과 반응 진행도 정지한다. 씬 종료 시 Pixi 입력 리스너를 정리한다.
- 조이스틱에서 손을 뗄 때 키보드 이동까지 해제하던 문제를 수정했다. 설정 진입·화면 크기 변경·포커스 상실·씬 종료에는 전체 입력과 포인터 캡처를 정리한다. 다른 손가락의 이동/취소 입력은 조이스틱을 해제하지 않는다. 우클릭은 조작을 시작하지 않는다.

## 검증

- 자동 테스트 42개 통과. 기존 타이틀/씬 수명주기, 플레이 클리어/복귀, 설정 일시정지/한영 전환, 프리셋, 구매/패스, Home 공유/저장, 저장소 차단 처리를 재검증했다.
- 새 테스트: 교감 연타·애니메이션 진행·자율 복귀·환영/공중 상태 보호, 로비 일시정지/HUD 분리/리스너 정리, 조이스틱과 점프 동시 입력·다른 포인터 무시·키보드 동시 사용·세로 회전 좌표·취소/리사이즈/씬 종료 시 캡처 정리.
- 타입 검사와 프로덕션 빌드 통과.
- 테스트는 모델과 가짜 DOM 입력 검증이다. 실제 브라우저 렌더링 테스트가 아니다. 브라우저 도구가 helper_unknown_error로 시작하지 못해 PC 크롬·모바일 크롬·삼성 인터넷의 화면/터치 실기기 점검은 미완료다. 따라서 계획 1번 전체를 완료로 처리하지 않는다.

## 남은 점검

실제 기기에서 Background 네 가지의 타원 제거, 타이틀→각 씬→복귀, 코기 터치/버튼 분리, 가로/세로 전환, 조이스틱+점프/공격, 인벤토리 스크롤, 설정 열기/닫기, 한영 전환과 재접속 저장 복원을 확인한다. 다음 개발 항목은 계획 3번 코스 검증이지만, 1번 실기기 확인은 계속 남겨둔다.
