# 캐릭터 꾸미기 프로토타입

- Character → 꾸미기 씬, 우측 상단 Close → 로비. 복귀 환영 연출 생략.
- 왼쪽은 기존 코기 확대 미리보기. 제자리 Idle과 주기적 이모션, 슬롯 선택 시 짧은 이모션 유지.
- 오른쪽 Hat / Body / Acc / Etc, 4열×4행 높이에서 초과 항목은 세로 스크롤. 탭과 Close 고정.
- 참고 이미지 29070.jpg의 인벤토리처럼 아이템 아래에만 옅은 회색 타원 그림자를 둔다. 큰 원형 버튼 배경과 테두리는 제거한다.
- 실제 아이템 아트 전에는 간단한 SVG 모자/상의/장식/리본 아이콘을 사용한다. 그림자는 낮은 알파의 radial-gradient로 자연스럽게 처리한다.
- 각 탭은 None + 더미 20개. 일부 번호는 같은 색상을 재사용한다. 번호는 접근성 이름으로 구분하며 화면에 큰 숫자를 표시하지 않는다.
- 현재 아이템 착용은 미구현. 미리보기·로비·플레이에 더미 장착 도형을 표시하지 않는다. 클릭하면 이모션과 선택 상태만 반영한다.
- Game의 선택 상태를 화면 재진입 시 유지하며 새로고침하면 초기화한다. 서버 저장·소유권·구매 없음.
- 테스트 30개: 진입·탭·아이콘·선택/해제·선택 유지·제자리 애니메이션·더미 미착용·재진입·정리 확인. 타입 검사 및 빌드 통과.
- 브라우저/모바일 실기기 렌더링과 터치 스크롤의 시각 검증은 별도 필요.
