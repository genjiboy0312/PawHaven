# 캐릭터 꾸미기 프로토타입

- Character → 꾸미기 씬, 우측 상단 Close → 로비. 복귀 환영 연출 생략.
- 왼쪽은 기존 코기 확대 미리보기. 제자리 Idle과 주기적 이모션, 슬롯 선택 시 짧은 이모션 유지.
- 오른쪽 Hat / Body / Acc / Etc, 4열×4행 높이에서 초과 항목은 세로 스크롤. 탭과 Close 고정.
- 참고 이미지 29070.jpg의 인벤토리처럼 아이템 아래에만 옅은 회색 타원 그림자를 둔다. 큰 원형 버튼 배경과 테두리는 제거한다.
- 실제 아이템 아트 전에는 간단한 SVG 모자/상의/장식/리본 아이콘을 사용한다. 그림자는 낮은 알파의 radial-gradient로 자연스럽게 처리한다.
- 각 탭은 None + 더미 20개. 일부 번호는 같은 색상을 재사용한다. 번호는 접근성 이름으로 구분하며 화면에 큰 숫자를 표시하지 않는다.
- 현재 아이템 착용은 미구현. 미리보기·로비·플레이에 더미 장착 도형을 표시하지 않는다. 클릭하면 이모션과 선택 상태만 반영한다.
- Game의 선택 상태를 화면 재진입 시 유지하며 새로고침하면 초기화한다. 서버 저장·소유권·구매 없음.
- 테스트 30개: 진입·탭·아이콘·선택/해제·선택 유지·제자리 애니메이션·더미 미착용·재진입·정리 확인. 타입 검사 및 빌드 통과.
- 브라우저/모바일 실기기 렌더링과 터치 스크롤의 시각 검증은 별도 필요.
## Pets 및 공용 프리셋 3개

- 탭 순서: Pets / Hat / Body / Acc / Etc. 진입 기본 탭은 Pets다.
- 현재 준비된 동물인 코기만 표시한다. 기존 idle 시트 프레임을 CSS 배경으로 재사용하며 추가 이미지 생성은 없다. 얼굴/전신 이미지 아래 옅은 그림자·이름, 선택한 동물에 체크를 표시한다.
- 동물 선택 시 왼쪽 미리보기를 바꾸고 짧은 이모션을 재생한다. Game의 활성 동물을 공유해 로비와 플레이에도 반영한다. 실제 고양이 등 새 동물 추가는 별도다.
- 왼쪽 캐릭터 아래 Preset 1 / 2 / 3 + Save를 탭과 무관하게 고정한다. 동물별 슬롯을 만들지 않는다.
- 슬롯 선택 시 저장된 동물 ID와 4개 분류의 선택값을 함께 불러온다. 빈 슬롯 선택은 저장 대상만 바꾸며 현재 조합은 유지한다. 사용할 수 없는 동물은 안내하고 현재 캐릭터를 유지한다.
- Save를 눌렀을 때만 선택 슬롯을 저장/덮어쓴다. 편집 후 저장 전에는 미저장 안내를 표시한다. 저장 데이터와 편집 상태는 복사해 서로 변형되지 않도록 한다.
- pawhaven.presets.v1에 공용 슬롯 3개를 기기별 localStorage로 저장한다. 새로고침 후에도 슬롯은 보존되며 눌러서 불러올 수 있다. 서버/다른 기기 동기화는 없다. 저장소 차단 시 현재 세션 안에서 동작한다.
- 선택한 슬롯 번호는 같은 실행 세션에서 꾸미기 씬을 다시 열 때 유지한다. 현재 편집 중인 조합은 새로고침 시 초기화되며 프리셋을 불러와 복원한다.
- 실제 아이템 착용 아트는 계속 미구현이다. 프리셋은 현재 더미 선택 데이터를 저장한다.
- 검증: 테스트 34개. 공용 슬롯 제한/저장 복원/복사 독립성/손상 데이터/차단 저장소, Pets 배치 및 선택, 슬롯 로드·저장·재진입과 동물 미리보기 교체·정리를 포함한다. 실기기 시각/터치 확인은 별도 필요하다.
