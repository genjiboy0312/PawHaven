# 캐릭터 꾸미기 프로토타입

- Character → 꾸미기 씬, Close(우측 상단) → 로비. 복귀 환영 연출은 생략한다.
- 왼쪽 절반은 기존 코기 확대 미리보기. 제자리 Idle과 주기적 이모션, 아이템 선택 시 짧은 이모션만 재생하며 이동하지 않는다.
- 오른쪽은 Hat / Body / Acc / Etc 탭과 회색 원형 슬롯. 4열×4행 높이의 영역에서 항목 초과 시 세로 스크롤한다. 탭과 Close는 고정이다.
- 탭마다 None + 색상 더미 20개. 실제 아이템 이미지 없이 번호·색상점과 간단한 모자/반다나/펜던트/리본 도형으로 연결을 검증한다. 일부 번호는 같은 색상을 재사용한다.
- Game이 OutfitState 하나를 소유하며 꾸미기/로비/플레이가 공유한다. 화면 재진입 시 유지, 새로고침 시 초기화. 서버 저장·인벤토리 소유권·구매 기능은 없다.
- 실제 장착 아트 및 애니메이션별 정밀 부착점은 후속 작업이다.
- 테스트 30개: 씬 진입·탭 구성·슬롯 선택·해제·항목 유지·제자리 Idle/Emote·로비 장착 반영·재진입·씬 정리 포함. 타입 검사 및 빌드 통과.
- 브라우저/모바일 실기기 렌더링과 터치 스크롤의 시각 검증은 별도 필요.
