# 이후 개발 계획

기준일: 2026-10-16. 이 문서는 현재 코드 기준의 후속 작업 제안이다. 후속 사용자 요청으로 1번 안정화 점검과 2번 로비 교감을 진행했다. 1번은 자동 검증/입력 수정 완료, 실기기 화면·터치 확인은 남아 있다. 2번은 구현/자동 테스트 완료. 상세: [STABILIZATION_M5.md](STABILIZATION_M5.md). 후속 요청으로 3번 코스 검증도 구현·자동 테스트 완료했다. 상세: [DUMMY_PLAY.md](DUMMY_PLAY.md). 4번 이후 기능은 별도 요청 시 진행한다. 새 문서는 MyAIAgent에 둔다.

## 현재 기준선

- 타이틀, 로비 자율 행동, 약 10초 더미 플레이와 Victory → 로비 복귀, Character, Home, Shop, Quest, Settings가 있다.
- Character: Pets / Hat / Body / Acc / Etc, 공용 프리셋 3개. 실제 의상 착용은 보류되어 있으며 아이템 선택 이모션만 적용한다. 현재 동물은 코기 한 마리다.
- Home: Background / Floor / Furniture / Etc. 캐릭터 없이 맵을 편집하며 로비에 공유된다. 가구·소품은 도형으로 정해진 위치에 각각 한 개만 표시한다. 큰 타원형 바닥 패치는 제거하고 Background와 Floor를 독립 선택한다.
- Shop 재화·구매·패스, Quest 패스 경험치·보상은 기기 내 테스트 데이터다. 실제 결제와 서버 검증은 없다. Daily / Weekly는 자리만 준비되어 있다.
- 설정의 사운드·컨트롤·화면·언어는 연결되어 있다. 계정은 Guest이고 Friends는 비활성이다. Supabase 연동과 기기 간 동기화는 아직 없다.
- GitHub Pages 배포, 자동 테스트 45개가 있다. 실제 PC·모바일 화면/터치 검증을 대신하는 테스트는 아니다.
- 원래 마일스톤 M0·M1·M3·M4는 코기 기준 완료, M2 고양이는 사용자 요청으로 보류다. M5 교감은 구현·자동 테스트 완료이며 실기기 확인은 남아 있다. M6 웹 프로토타입 마무리는 아래 순서에 연결한다. 기존 번호를 다시 부여하지 않는다.

## 권장 실행 순서

| 순서 | 작업 | 범위와 완료 기준 | 선행 조건 |
|---|---|---|---|
| 1 | 프로토타입 안정화 | PC 크롬·모바일 크롬·삼성 인터넷에서 타이틀→로비→각 씬→복귀 확인. 가로 화면, 세로 접속 시 회전, 조이스틱과 액션 동시 입력, 설정 일시정지/복귀, 스크롤, 한영 전환, 새로고침 저장 복원을 확인하고 발견된 버그 수정 | 현재 배포본 |
| 2 | 로비 교감 M5 | 코기를 클릭/터치하면 기존 이모션으로 반응. 연속 입력에 겹치거나 멈추지 않으며 반응 후 자율 행동으로 복귀. UI 클릭은 코기 반응을 발생시키지 않음 | 1 |
| 3 | 플레이 코스 검증 | 한 코스에 낮은 장애물·간단한 발판을 추가해 점프/착지/공중 공격/지상 대시를 검증. 벽 통과·지형 끼임·피니시 중복 처리를 방지. 실패 시 재시작과 클리어 복귀 동작을 일관되게 처리 | 1, 코스 규칙 확정 |
| 4 | 실제 꾸미기 최소 세트 | 모자 한 개를 실제 픽셀 에셋으로 연결. Idle·Run·Jump·Attack·Skill에서 위치/방향 확인. Character·로비·게임과 프리셋에 동일 적용. Home은 실제 배경·바닥 한 세트와 가구 한 개부터 교체하고 제한된 배치 영역에서 이동·제거·저장 검증 | 1, 아트 준비. PIXEL_ART_AGENT.md 준수 |
| 5 | 계정·클라우드 저장 | Supabase 대상 프로젝트와 로그인 방식을 정한 뒤 프로필·소유 아이템·프리셋·Home 저장 연동. 계정별 접근 제한, Guest 데이터 이전, 기기 간 충돌/오프라인 실패 정책 검증. 재화·보상 변경은 서버에서 검증 | 1, 저장 데이터 구조 확정, 연결 대상 확인 |
| 6 | 퀘스트·상점 규칙 완성 | Daily·Weekly에 실제 조건/진행도/보상을 연결. 서버 시간 기준 초기화·시즌 종료·중복 지급 방지. Shop 패스 구매와 Quest 패스 보상은 같은 시즌 상태 사용. 테스트 재화와 운영 데이터 분리 | 3, 5 |
| 7 | 공개 테스트 정리 M6 | 주요 흐름 회귀 확인, 모바일 성능·로딩·실패 복구 점검, 안내/버전 표시, 배포 검증. 실제 결제는 판매 플랫폼과 검증 방식을 정한 별도 단계로 진행 | 1~6 |

3~5의 세부 순서는 다음 기능 요청에 따라 조정할 수 있다. 다만 서버에서 검증하는 재화·시즌 보상을 공개하기 전에는 5가 필요하다.

## 바로 다음 작업 제안

**1번 실기기 화면·터치 점검을 마무리한다. 2번 쓰다듬기는 구현·자동 테스트를 마쳤다.** 3번은 장애물·발판·낙하/재시작 및 클리어 복귀 구현·자동 테스트를 마쳤다. 다음 기능 개발 후보는 4번 실제 꾸미기 최소 세트다. 점검 결과는 재현 방법·수정 결과·남은 문제만 기록한다.

## 보류 범위

- 고양이 M2, 새 동물 대량 추가, 사진 기반 반려동물 생성: 별도 요청 시 진행.
- Friends 소셜 기능·멀티플레이, 자유로운 다중 가구 배치, 모바일 앱 패키징: 핵심 흐름 검증 후 별도 기획.
- 실제 결제·유료 시즌패스·운영 경제: 로그인/서버 검증과 판매 정책 확정 후 진행. 현재 테스트 구매를 실제 과금으로 취급하지 않는다.

## 작업 완료 규칙

각 단계는 요청된 범위만 구현하고 관련 자동 테스트와 타입 검사·빌드를 통과시킨다. 화면/입력 변경은 가능하면 실제 브라우저와 모바일에서도 확인한다. 확인하지 못한 항목은 미검증으로 남긴다. 배포 후 해당 커밋의 Actions 성공과 배포 파일 갱신을 확인한다.
