# 이후 개발 계획

기준일: 2026-10-16. 이 문서는 현재 코드 기준의 후속 작업 제안이다. 후속 사용자 요청으로 1번 안정화 점검과 2번 로비 교감을 진행했다. 1번은 자동 검증/입력 수정 완료, 실기기 화면·터치 확인은 남아 있다. 2번은 구현/자동 테스트 완료. 상세: [STABILIZATION_M5.md](STABILIZATION_M5.md). 후속 요청으로 3번 코스 검증도 구현·자동 테스트 완료했다. 상세: [DUMMY_PLAY.md](DUMMY_PLAY.md). 4번 이후 기능은 별도 요청 시 진행한다. 새 문서는 MyAIAgent에 둔다.

- Home: Background / Floor / Furniture / Etc. 캐릭터 없이 맵을 편집하며 로비에 공유된다. 가구·소품마다 기본 3개씩 제공하고 여러 개를 독립 배치·드래그·회수할 수 있다. 남은 수량 표시·0개 흐림·위치 자동 저장을 지원한다. 픽셀 배경·바닥·쿠션을 연결했다. 상세: [HOME.md](HOME.md). 큰 타원형 바닥 패치는 제거하고 Background와 Floor를 독립 선택한다.

- 설정의 사운드·컨트롤·화면·언어는 연결되어 있다. 계정은 Guest이고 Friends는 비활성이다. Supabase 연동과 기기 간 동기화는 아직 없다.
- GitHub Pages 배포, 자동 테스트 51개가 있다. 실제 PC·모바일 화면/터치 검증을 대신하는 테스트는 아니다.
- 원래 마일스톤 M0·M1·M3·M4는 코기 기준 완료, M2 고양이는 사용자 요청으로 보류다. M5 교감은 구현·자동 테스트 완료이며 실기기 확인은 남아 있다. M6 웹 프로토타입 마무리는 아래 순서에 연결한다. 기존 번호를 다시 부여하지 않는다.

## 바로 다음 작업 제안

**1번 실기기 화면·터치 점검을 마무리한다. 2번 쓰다듬기는 구현·자동 테스트를 마쳤다.** 3번은 장애물·발판·낙하/재시작 및 클리어 복귀 구현·자동 테스트를 마쳤다. 4번의 산타모자 최소 세트도 구현·자동 테스트 완료. 산타모자 착용은 사용자 확인 완료. Home 픽셀 배경·바닥·쿠션 및 가구/소품 제한 배치도 구현·자동 테스트 완료했고, 실제 화면 확인은 남아 있다. 다음 후보는 5번 계정·클라우드 저장 기획/연동이다. 점검 결과는 재현 방법·수정 결과·남은 문제만 기록한다.
