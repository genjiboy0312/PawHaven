# Friends 실제 연동 1단계 (2026-10-23)

## 로비 요청 수 배지 (2026-10-23, 조회 수명은 이전 설명보다 우선)
- 로비 Friends 우상단에 받은 대기 요청 수를 표시한다. 0은 숨기고 100은 99+로 축약한다. 기존 퀘스트 알림의 테두리·색상·위치를 재사용하며 새 리소스나 SQL은 없다. 버튼 접근성 문구도 한영으로 요청 존재를 알린다.
- Game이 생성한 계정별 FriendsClient를 패널과 배지가 공유한다. 닉네임이 있는 로그인 계정은 로비 진입 시 기존 8초 조회를 시작한다. 패널을 닫아도 조회를 유지하고 플레이 진입 시 멈춘다. 백그라운드 조회는 기존 정책대로 생략하며 복귀하면 갱신한다. 수락·거절 응답을 같은 snapshot에 반영하고 로비 재개 시 즉시 배지를 갱신한다.
- FriendsPopup의 keepAlive는 Game에서만 활성화한다. 기본 팝업의 닫기 시 정리 동작은 유지하고, Game 계정 변경/종료에서 팝업 destroy가 클라이언트·타이머·이벤트까지 정리한다. 로그아웃 후 이전 계정의 요청 수를 사용하지 않는다.
- 전체 218개 테스트·타입 검사·빌드 통과. 기존 로비 테스트에 숫자/숨김/99+/접근성 검증을 추가하고 계정 소유 조회의 패널 닫기 유지·계정 종료 정리를 검증했다. Chrome headless 800×540에서 실제 LobbyHud 배지 표시와 경계를 확인했다. 운영 두 계정의 요청 교환은 별도 사용자 확인이 필요하다.

## 공원 프로필 연결 (2026-10-25)
- 공원에서 강아지를 누르면 ParkProfilePopup이 기존 FriendsClient/friends_command를 재사용해 친구 추가·요청 중·친구·받은 요청 수락을 표시한다. 자기 자신에게는 관계 버튼을 표시하지 않는다. 닉네임 검색 없이 서버 참가자 UUID로 요청한다. 상세: [PARK.md](PARK.md).
- 신규 SQL/리소스/독립 친구 상태는 없다. 프로필 닫기/씬 종료 후 폴링·구독·늦은 응답을 정리하되 계정 소유 클라이언트는 파기하지 않는다.

## 범위와 UI
- 기존 Friends / Add Friend / Requests 패널과 스타일을 재사용한다. 닉네임 검색, 친구 요청, 수락·거절·요청 취소, 친구 목록·삭제를 연결한다. 온라인 표시와 방 초대는 아래 2단계에서 확장한다.
- 로그인·닉네임 설정이 필요하면 Account 설정으로 연결한다. 더미 사용자를 게임에 생성하지 않는다. 요청 탭은 받은 요청 수를 표시하며 보낸 요청도 함께 관리한다.
- 친구 삭제는 기존 ConfirmPopup을 사용한다. 갱신으로 원래 버튼이 교체돼도 취소 시 닫기 버튼으로 포커스를 복구한다.
- 로비 일시정지·배경 inert, ×/Escape/직접 누른 배경 닫기, 키보드 Tab 순환·한영 전환을 유지한다. 검색 초안·커서·스크롤은 서버 갱신 중에도 보존한다.

## 서버와 상태
- supabase/migrations/202610230009_friends.sql은 2026-10-23 사용자가 SQL Editor 실행 완료를 확인했다. 기존 계정 migration이 선행되어야 한다. 운영 계정 두 개의 실제 요청·수락 확인은 별도로 남아 있다.
- player_friendships는 정렬된 두 UUID의 복합 키로 중복을 막는다. pending/accepted 및 요청자를 기록하고 수신자만 수락·거절할 수 있다. 교차 요청을 자동 수락하지 않는다. 양쪽이 같은 친구 관계를 공유하며 계정 삭제 시 정리된다.
- friends_command는 auth.uid()를 사용하고 SECURITY DEFINER/search_path 고정·함수 권한 제한을 적용한다. 테이블은 RLS로 당사자 읽기만 허용하고 직접 쓰기는 막는다. player_profiles의 기존 본인 읽기 정책은 확장하지 않는다.
- 검색은 영문·숫자·한글·밑줄 2~16자의 대소문자 무시 접두사 검색이며 본인을 제외하고 최대 20명이다. UUID·닉네임·관계 상태만 반환하고 이메일·세이브·재화는 반환하지 않는다. 밑줄을 와일드카드로 해석하지 않는다.
- 초기 한도는 친구 100명, 보낸 대기 요청 20건, 받은 대기 요청 100건이다. 쓰기는 기존 멀티 RPC처럼 짧은 advisory transaction lock으로 직렬화한다. 중복 전송·반복 삭제 등 재시도를 안전하게 처리한다.
- FriendsClient는 계정 UUID에 고정된다. RPC 전 현재 세션의 소유자를 확인하고 그 토큰을 명시해 요청한다. Game의 계정 데이터 재로드 시 기존 팝업·클라이언트를 파기하고 새 계정용으로 만든다.
- 별도 로컬 친구 저장소나 낙관적 친구 승격은 없다. 서버 응답이 목록의 기준이다. 단일 요청 처리·15초 제한·취소 신호·세대 번호로 중복 입력과 닫은 뒤/이전 계정의 늦은 응답 반영을 막는다.
- 팝업이 열려 있는 동안만 8초마다 갱신한다. 숨겨진 문서에서는 요청을 보내지 않고 포커스/온라인/복귀 시 갱신한다. 닫기·계정 변경·종료 시 폴링과 이벤트·진행 중 요청을 정리한다. 새로고침 버튼도 제공한다.
- SQL 미적용·접속 오류·잘못된 검색·한도·사라진 요청은 번역된 상태 문구와 재시도로 처리한다.

## 2단계: 온라인 상태·친구 방 초대 (2026-10-23)
- 기존 친구 목록에 온라인/플레이 중/대기방/오프라인을 표시한다. 상태 조회가 실패하거나 마지막 응답이 15초 이상 지났다면 확인 중으로 표시한다. 닉네임 검색 결과에는 다른 사용자의 활동을 공개하지 않는다.
- 대기방 방장에게만 친구 초대 버튼을 노출한다. 기존 FriendsPopup을 열고 온라인 로비 친구만 초대 가능하다. 기존 URL 초대는 링크 공유로 구분한다. 다른 참여자는 친구 초대 버튼을 보지 않는다.
- FriendActivity는 계정별 옵저버이며 5초마다 조회한다. 존재 기록 쓰기는 20초마다 또는 플레이 상태 변경 시만 한다. 백그라운드에서는 조회를 멈추고 복귀하면 갱신한다. 마지막 기록 75초 후 오프라인으로 처리하므로 앱 강제 종료 직후 즉시 오프라인을 보장하지 않는다.
- 초대 팝업은 기존 ConfirmPopup을 재사용한다. 로비에서 다른 패널이 없을 때만 표시하고 플레이/꾸미기/설정/대기방을 방해하지 않는다. 유효한 초대는 로비 복귀 후 표시하며, 60초가 지난 초대는 표시하지 않는다. 초대 수락·거절 중 버튼 중복 입력을 막고 배경 inert·일시정지·포커스를 복구한다.
- 같은 친구에게 30초 동안 재초대할 수 없다. 신규 ticket으로 이전 팝업이 새로운 초대를 잘못 수락·거절하지 못하게 한다. 방장 변경·방 삭제·게임 시작·만석·친구 삭제·만료 시 초대를 숨기거나 수락을 거절한다.
- supabase/migrations/202610230010_friend_invites.sql 실행이 필요하다. 2026-10-23 사용자가 운영 SQL 실행 완료를 확인했다. player_presence와 friend_room_invites는 RLS 활성 및 직접 읽기/쓰기 권한 회수, friend_activity RPC는 인증 계정에만 실행을 허용한다. 수락은 기존 multiplayer_command의 join과 같은 트랜잭션에서 수행해 마지막 자리를 중복 배정하지 않는다. 초대 응답을 잃어도 다음 조회에서 입장한 방으로 복구하며, 티켓 재수락은 중복 입장하지 않는다.
- 서버 응답만을 상태 기준으로 사용하고 이전 계정 요청·타이머·이벤트·팝업은 계정 변경/종료 시 정리한다. 친구 패널을 닫아도 초대 수신용 조회는 유지한다. SQL 미적용 시 기존 친구 기능은 계속 동작하며 초대 설정 안내를 표시한다.
- 새 이미지·의존성 없이 UI와 방 입장 로직을 재사용했다. 217개 전체 테스트·타입 검사·빌드, PGlite 권한/만료/쿨다운/정원/수락/거절/재실행 검증 및 Chrome headless 실제 DOM의 패널 중복 방지·입력 복구·플레이 중 보류·수락 응답 유실 복구·온라인 친구만 초대 가능을 확인한다. 800×540 한글 친구 목록/초대 팝업과 1280×720 영어 대기방도 확인했다. 운영 두 계정 테스트는 SQL 반영 후 별도로 필요하다.

- 0a8d589의 GitHub Actions 배포 성공과 운영 페이지 JS/CSS의 로컬 빌드 일치를 확인했다. 실제 두 계정 초대 교환은 사용자 테스트가 남아 있다.
